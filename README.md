# AWS Certified Cloud Practitioner (CLF-C02) Exam Simulator

An interactive exam simulation and study platform built for the **AWS Certified Cloud Practitioner (CLF-C02)** certification. It features **550 scenario-based questions** weighted strictly to the official AWS exam blueprint across all four domains — Cloud Concepts, Security & Compliance, Cloud Technology & Services, and Billing, Pricing & Support.

Practice mode gives instant feedback with detailed explanations for every answer option and links to official AWS documentation. Exam mode simulates the real test environment with a 65-question timed session, a flagging system, and a scaled score report upon completion. A mistake bank automatically tracks incorrect answers so you can focus on weak areas.

Progress, bookmarks, and attempt history are stored locally in the browser by default — no account required. Optional account creation enables cross-device sync through a self-hosted backend.
