## Overview

An interactive exam simulation and study platform built for the **AWS Certified Cloud Practitioner (CLF-C02)** exam. It features **1,142 scenario-based questions** aligned with the four core AWS exam domains:

- **Domain 1**: Cloud Concepts (24%)
- **Domain 2**: Security and Compliance (30%)
- **Domain 3**: Cloud Technology and Services (34%)
- **Domain 4**: Billing, Pricing, and Support (12%)

## Key Features

- **1,142 Questions**: Comprehensive question bank with detailed rationales for correct and incorrect choices.
- **Practice Mode**: Instant answer feedback, domain filters, full-text search, and bookmarking.
- **Timed Exam Simulation**: 65-question timed mock exam matching the official AWS format, with question flagging and post-test score review.
- **Mistake Bank & Analytics**: Automatic tracking of incorrect answers and review breakdown by domain.
- **12 Custom Color Themes**: Handcrafted accessible themes including the default *Oxford Navy & Gilded Amber*, *Tokyo Midnight*, *Emerald Pine*, and more.
- **Local-First**: Progress, bookmarks, and attempts save locally in your browser with zero sign-up required.
